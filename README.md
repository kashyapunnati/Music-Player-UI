# 🎵 Music Player UI

## 📖 Description

This project is a responsive Music Player UI developed using HTML5, CSS3, and JavaScript.

It allows users to play songs, pause/play audio, switch between previous and next tracks, control the volume, and select songs from a playlist.

## ✨ Features

- ▶️ Play and pause music
- ⏮ Previous song button
- ⏭ Next song button
- 🎵 Playlist with multiple tracks
- 📊 Progress bar synchronized with audio playback
- ⏱ Current time and total duration display
- 🔊 Volume control
- 🔄 Automatically plays the next song when a track ends
- 📱 Responsive design
- 🎧 HTML5 Audio API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- DOM Manipulation
- Event Listeners
